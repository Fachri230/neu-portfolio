# Abyss Portfolio (React + Tailwind CSS + HTML5)

## Run it
```bash
npm install
npm run dev      # open the local URL shown in the terminal
npm run build    # production build in /dist
```

## Make it yours
1. Put your photo in `public/owner.jpg` (a portrait, ideally with a plain or transparent background).
2. Optional: put your resume in `public/cv.pdf`.
3. Edit your name, texts, skills, projects and links in `src/data/content.js`.
